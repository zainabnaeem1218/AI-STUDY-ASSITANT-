# AI-STUDY-ASSITANT-
A BEGINNER FRIENDLY  python study assistant project .
Features:
* Asks the student’s name
* Allows the student to choose a topic
* Provides a simple explanation of Artificial Intelligence
* Gives a short quiz
* Calculates the student’s score

What I Learned

Through this project, I learned how to use Python inputs, conditional statements, and basic scoring logic to create an interactive learning program.

Future Improvements

I would like to add more study topics, more quiz questions, and improve the user interface in the future.
